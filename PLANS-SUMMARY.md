## Plan 2: Repository Migration Plan

**File:** `MIGRATION-PLAN.md`

**Purpose:** Move everything to a clean, branded repository

**Duration:** 1 day (after QC completion)

### 5 Phases

| Phase | Focus | Time | Key Tasks |
|-------|-------|------|-----------|
| **Phase 1** | Preparation | 1-2h | Create structure, plan mapping, .gitignore |
| **Phase 2** | Copy & Clean | 2-3h | Copy all files, remove unwanted, verify structure |
| **Phase 3** | Add Branding | 2-3h | Brand guidelines, colors, logo, visual identity |
| **Phase 4** | Update Docs | 1-2h | Fix references, update paths, add brand info |
| **Phase 5** | Finalize & Publish | 1h | Git setup, GitHub repo, push, configure |
| **Phase 6** | Post-Migration | 30m | Update old repo, external links, announce |

### Key Decisions to Make

1. **Repository Name**
   - Recommendation: `marketing-tools-marketplace`
   - Alternative: `marketflow`, `claude-marketing-tools`

2. **Repository Structure**
   - Recommendation: Single repo with both marketplace and course
   - Alternative: Two separate repos

3. **Organization vs Personal**
   - Organization: More professional, team-ready
   - Personal: Simpler, can transfer later

### What Gets Migrated

**Include:**
- ✅ Marketplace infrastructure
- ✅ Both plugins (compounding-marketing, content-factory)
- ✅ Course content (all modules)
- ✅ Documentation
- ✅ Examples and templates

**Exclude:**
- ❌ Old website files
- ❌ Personal/temp files
- ❌ QC documents

### Branding Added

- `brand/guidelines.md` - Complete brand voice and visual guidelines
- `brand/colors.md` - Color palette and usage
- `brand/logo.md` - Logo specifications (placeholder for now)
- Updated documentation with brand consistency
