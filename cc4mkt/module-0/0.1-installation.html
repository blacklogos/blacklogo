Installing Claude Code (2025 Edition)

In this lesson, you'll install Claude Code using the new native installer. Good news: No Node.js required! The 2025 version uses a native installer that's faster and easier to set up.

What You'll Install

  • Claude Code: Native binary installer (auto-updates included)
  • Anthropic Account: For authentication
  • A code editor: VS Code (optional but recommended)

System Requirements

Before we begin, make sure your computer meets these requirements:

  • Operating System: macOS, Windows 10+, or Linux/WSL
  • RAM: At least 4GB (8GB+ recommended)
  • Disk Space: 500MB free space
  • Internet: Stable internet connection

Step-by-Step Installation

1Install Claude Code

For macOS, Linux, or WSL:

curl -fsSL https://claude.ai/install.sh | bash

For Windows:

Download the installer from claude.ai/download and run it.

The native installer will automatically:

  • Install Claude Code binary
  • Set up auto-updates
  • Configure your system PATH

No Node.js required! The 2025 native installer is a standalone binary that manages everything for you.

2Set Up Authentication

When you first run Claude Code, it will prompt you to authenticate. You have two options:

Option 1: Claude Console (API Key)

  1. Visit console.anthropic.com
  2. Create an account or sign in
  3. Get your API key from the console
  4. Set it in your terminal:
# Mac/Linux
export ANTHROPIC_API_KEY='your-key-here'

# To make it permanent, add to ~/.zshrc or ~/.bashrc
echo 'export ANTHROPIC_API_KEY="your-key-here"' >> ~/.zshrc

# Windows PowerShell
$env:ANTHROPIC_API_KEY='your-key-here'

Option 2: Claude App (OAuth)

If you have a Claude Pro or Max subscription, you can use OAuth authentication through the Claude app.

Note: API usage requires active billing at console.anthropic.com, or a Claude Pro/Max subscription.

3Verify Installation

Open your terminal/command prompt and run:

claude --version
claude doctor

The claude doctor command checks your installation and shows:

  • Installation type (native or npm)
  • Version information
  • Configuration status
  • Any potential issues

4Install VS Code (Optional)

While not required, Visual Studio Code makes it easier to view and edit marketing files.

Download it from code.visualstudio.com.

After installation, you can open any folder with:

code .

Bonus: Claude Code also has a VS Code extension (beta) that lets you use it directly in your editor!

Verify Your Installation

Let's make sure everything is working correctly. In your terminal, run:

claude --version
claude doctor

You should see the Claude Code version number and a diagnostic report. If you do, congratulations! You're all set up.

Understanding Your 2025 Setup

Now that you've installed Claude Code, here's what you have:

  • Native Binary: Claude Code runs as a standalone application (no Node.js dependency)
  • Auto-Updates: Claude Code automatically updates itself with latest features
  • Claude Sonnet 4.5: The world's best coding model (now default)
  • Checkpoints: Press Esc+Esc to rewind any changes
  • Subagents: Parallel AI assistants for specialized tasks
  • Hooks: Automation that runs at specific workflow points
  • VS Code Extension (optional): Use Claude Code directly in your editor

Common Installation Issues

Issue: "command not found: claude"

Solution: Close and reopen your terminal to refresh PATH. If still not working, try reinstalling or check your system PATH settings.

Issue: "Installation failed"

Solution: Check your internet connection. Try with elevated privileges if needed. Verify firewall/antivirus isn't blocking the installer.

Issue: "API key not working"

Solution: Verify your key at console.anthropic.com. Check for extra spaces or quotes. Restart terminal after setting the environment variable.

Issue: "Already have npm version installed"

Solution: Run claude install to migrate from npm to the native installer. This provides better auto-updates and performance.

Still Having Issues?

Run claude doctor to diagnose problems, or visit the Claude Code documentation for detailed troubleshooting.
