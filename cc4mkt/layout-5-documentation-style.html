Welcome to MarketFlow

Learn how MarketFlow connects Claude Code to your marketing workflow and introduces the foundational concepts you'll use throughout the course.

What is MarketFlow?

MarketFlow is a sample marketing project structure that demonstrates how to organize your Claude Code workflow for marketing work. It's designed to show you:

  • How to structure your marketing files for easy access
  • How to define custom agents for your specific marketing needs
  • How to use templates for repeated tasks
  • How to maintain brand consistency through AI
  • How to compound your learning with each project

Tip: Think of MarketFlow as a template you can customize for your own marketing projects. You'll clone it, modify it for your brand, and use it as the foundation for all your Claude Code marketing work.

Core Components

MarketFlow includes several key directories:

Project Directory

The main folder that contains your entire marketing project structure:

marketflow/ ├── .claude/ # Claude Code configuration │ └── CLAUDE.md # Brand guidelines and context ├── campaigns/ # Campaign briefs and planning ├── content/ # Generated content (blogs, emails, social) ├── templates/ # Reusable templates └── research/ # Competitor and market research

CLAUDE.md - Your Brand Memory

This file stores your brand guidelines, tone of voice, target audiences, and other context. Claude Code reads this automatically, so all your AI work stays on-brand.

Important: Keep your CLAUDE.md updated as your brand evolves. This is the single source of truth for brand consistency across all AI-generated content.

Your First Steps

Here's how to get started with MarketFlow:

  1. Clone the MarketFlow repository to your local machine
  2. Open the MarketFlow folder in Claude Code
  3. Edit CLAUDE.md with your brand information
  4. Create your first campaign folder in campaigns/
  5. Start working with Claude Code to plan your campaign

Key Concepts

1. Brand Context

Claude Code reads your CLAUDE.md file to understand your brand. The more detailed and specific you are, the better Claude can help you maintain consistency.

2. Reusable Templates

Templates in MarketFlow are starting points for your work. You'll customize them for each campaign, then save the customized versions as new templates for future use.

3. Custom Agents

You can create custom agents for specific marketing roles (brand voice guardian, SEO specialist, copywriter). These agents review your work and provide feedback automatically.

4. Compounding Knowledge

As you complete more campaigns, your templates improve, your agents learn your style, and your processes get more efficient. This is the "compounding" effect that makes Claude Code powerful.
